## Featured projects

### 🤖 [QuadInvestorAI](https://github.com/HadiaSajjad123/QuadInvestorAI)
AI-powered portfolio advisor for Pakistan Stock Exchange (PSX) equities.

- Trains on 15 years of Kaggle PSX history and can pull live data from the PSX data portal
- XGBoost + LSTM weighted ensemble for price-direction prediction
- CVXPY portfolio optimization and SHAP feature explanations
- Streamlit dashboard with generated investment reports

**Stack:** Python · XGBoost · TensorFlow/Keras · CVXPY · SHAP · Streamlit

---

### 📱 [MoodSnap Vision](https://github.com/HadiaSajjad123/MoodSnapVision)
Emotion-aware Android app that detects mood from the face and voice, then adapts content and UI.

- Real-time facial emotion detection (ML Kit + TensorFlow Lite) and voice-based detection when the phone is idle
- Mood-based recommendations (music, Quran recitation, wellness videos) and mood analytics charts
- Background services with WorkManager; local storage with Room and DataStore; Firestore sync
- Public repo shows the UI and service structure; ML models and database layer are intentionally withheld

**Stack:** Kotlin · MVVM / Clean Architecture · TensorFlow Lite · ML Kit · CameraX · Room · Firebase · Media3
